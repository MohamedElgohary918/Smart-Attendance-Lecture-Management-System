# Smart Attendance System

A mobile-based solution that automates university lecture attendance using AI facial recognition.

## 🎯 Project Overview

- **Student App**: Register, view schedule, track attendance
- **Professor App**: Manage courses, view attendance reports  
- **AI Module**: Automatic face recognition during lectures
- **Backend**: FastAPI server with PostgreSQL database
